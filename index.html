K4 Event Viewer — Help

Purpose

This tool helps K4 administrators view, filter, and analyze k4_event.log files from K4 Server diagnostics packages. Upload one or more log files to see parsed event data in a searchable, sortable table with text-object grouping.

How to Use

  1. Download the K4 diagnostics package from the K4 Server section of K4 Admin.
  2. Extract the package and locate the k4_event*.log files in the K4 Server Logs folder.
  3. Drag and drop the log files onto this page, or click Browse to select them.
  4. Use the filters, sorting, and grouping controls to explore the data.
  5. Export your filtered view as CSV for further analysis in Excel.

Enabling Event Logging

Event logging is disabled by default. To enable it, edit K4_Event_Log_Config.logback located at C:\ProgramData\vjoon\K4_Server. Change the logger level from "OFF" to "INFO" for the com.vjoon.VJ_AuditEvent logger.

Tips

  • Text Object Grouping collapses child text objects under their parent article, reducing noise by ~79%. Adjust the time window (1–60s) to tune grouping sensitivity.
  • Multi-column sort: Shift+click column headers to add secondary sort criteria.
  • Article labels: Click a group's article name to rename it. Labels persist in your browser across sessions. Use Manage Labels to export/import.
  • Local time: Toggle "Show local time" to convert server timestamps to your browser's timezone.
  • Session banding: Toggle to add color-coded left borders for visual session tracking.
  • Export: When grouping is enabled, choose between flat, summary, or details CSV exports.
